# Word 报告与证据目录规格

## 一、证据目录复刻基线

参考证据目录共244项，按五组跨表连续编号：

1. 权属类证据。
2. 知名度类证据。
3. 被告侵权类证据。
4. 混淆类证据。
5. 共同侵权类证据。

每组独立表，固定五列：

序号 | 证据名称 | 证据来源 | 单独证明目的 | 页码

每组包含淡黄色跨五列组标题、灰色列标题、共同证明行和证据行；跨页重复组标题与列标题。用同一 Word numId 跨五表连续编号，不手写数字。

## 二、页面参数

- A4横向：16838 x 11906 twip。
- 页边距：上/下1800，左/右1440 twip。
- 页眉851、页脚992 twip。
- 表格列宽：681 / 4956 / 1086 / 6080 / 1371 twip。
- 正文中文仿宋、英文 Times New Roman、10.5pt，行距276 twip。
- 固定表格布局，单元格左右边距108、上下0，垂直居中。
- 序号、来源、页码居中；名称和证明目的两端对齐。
- 边框0.5pt、#BEBEBE；列标题#ECECEC；组标题#FEF2CC。
- 页脚为动态 PAGE / NUMPAGES。

## 三、动态五组

1. 权属及原告资格。
2. 知名度、贡献率及利润。
3. 侵权行为、渠道、规模、地域及销量。
4. 混淆、主观故意及明知。
5. 主体关联、参照赔偿、合理开支及特殊因素。

## 四、文字标准

证据名称写“材料主体 + 材料类型 + 核验附件”，可包含公证书号、录像、截图、时间戳证书、登记查询页和链接。

单独证明目的按事实链写：

- 形成时间和访问时间；
- 地点、平台、店铺、商品/型号；
- 行为主体、经营者、付款/收款、发货和生产连接点；
- 数量、价格、销量、金额、地域、渠道或产能；
- 与具体权利客体的关联；
- 材料局限、事实分级和仍需补强步骤。

不要只写“证明侵权”。法律结论与事实材料分开。

## 五、报告附加部分

证据目录后附：

- 待补证与人工闸门；
- 访问失败和事实冲突；
- 附件完整性与 SHA-256；
- 自动调查边界和律师复核提示。

附件页码未知时写“对应电子文件”，不得伪造页码。需要形成合订本时，由人工排版后回填连续页码并再次校验。
