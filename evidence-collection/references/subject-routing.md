# 检索对象路由

本文件规定每一行应当搜索谁。用户提供权利人和疑似侵权链接后，除 `2-3-1` 至 `2-3-5` 的原告知名度调查外，全部项目均以链接中的**被告商品及其派生主体**为主检索对象。

不得因为原告品牌更容易搜索，就把原告商品、原告旗舰店或原告集团资料写入被告商品相关条目。

## 一、被告商品种子字段

打开疑似侵权链接后，先建立一份被告商品种子，至少提取：

- `product_name_exact`：页面显示的商品完整名称。
- `defendant_brand`：商品、包装或标题实际显示的品牌、中英文标识。
- `model_sku_spec`：型号、SKU、货号、规格、容量、颜色或版本。
- `store_account`：店铺、账号、供应商名称及平台 ID。
- `operator`：店铺营业执照经营主体或账号认证主体。
- `manufacturer_chain`：生产商、注册人、备案人、委托方、经销商。
- `contact_clues`：电话、地址、发货地、收款主体、发票抬头。
- `regulatory_clues`：备案号、许可证号、执行标准、专利号、条码。
- `visual_text_clues`：包装 OCR 文字、独特宣传语、主图和详情图特征。
- `seed_url`：原始链接、最终 URL、平台商品 ID、店铺 ID 和访问时间。

各角色必须分开记录。店铺、经营主体、供应商、生产商、备案人和发货人不得未经来源支持相互等同。

## 二、提取闸门

在开始 61 项跨平台调查前，必须先取得 `product_name_exact`，并尽可能取得品牌、型号、店铺和主体字段。

- 页面需要登录时，由 AI 打开登录界面，用户仅负责扫码并回复“已登录”；登录后的浏览、截图、提取和归档由 AI 完成。不得索取或代填密码、验证码、OTP或任何认证材料。
- 页面受验证码、风控或技术问题阻断时，先记录 `BLOCKED`，不得改搜原告商品凑结果。
- 仅能从 URL、搜索摘要或相似页面推测商品名称时，只能标为 `LEAD_ONLY`，不能通过提取闸门。
- 未取得被告商品名称时，依赖商品名称的后续行不得写成已核验；可以继续查已明确的店铺 ID、主体名或平台商品 ID，但必须说明证据边界。
- 被告商品身份与链接没有直接来源对应时，不得把同名、同图或同类商品自动视为涉案商品。

## 三、查询扩展顺序

后续检索按以下顺序逐层扩展。上一层没有结果时才进入下一层，并保留查询式和访问时间。

1. 精确商品名：`"被告商品完整名称"`。
2. 品牌和品类：`"被告品牌" "商品类别"`。
3. 型号和规格：`"型号/SKU/货号"`、`"型号" "规格"`。
4. 商品与店铺：`"商品名" "店铺名"`、`"品牌" "账号名"`。
5. 商品与主体：`"商品名" "经营主体"`、`"品牌" "生产商"`。
6. 主体关系：经营主体、生产商、备案人、股东、高管、地址、电话的组合查询。
7. 监管字段：备案号、许可证号、执行标准、条码、专利号的精确查询。
8. 图文反查：使用被告商品主图、包装 OCR 原文和独特宣传语查找同源页面。
9. 类别数据：确无单品数据时，才检索与被告商品严格对应的行业类别、同类企业或中性样本，并说明不能直接等同涉案商品。

不得从“原告品牌 + 仿品”“原告品牌 + 同款”等宽泛查询起步。原告名称只可在白名单知名度条目或确需核验权利登记、双方关系、混淆比较时作为限制词使用，不能取代被告商品主词。

## 四、61 项检索对象路由

以下路由覆盖全部 61 项。除原告知名度白名单外，每一项均从被告商品种子出发。

| 编号 | 主检索对象和派生方向 |
|---|---|
| `1-1-1` | 被告商品、店铺、订单、收款、物流、发货和实物链。 |
| `1-1-2` | 从被告店铺派生经营主体、关联主体及生产能力。 |
| `1-1-3` | 用被告商品名、品牌、型号和主体查展会身份。 |
| `1-1-4` | 用被告商品和主体查其官网、账号及生产销售自认。 |
| `1-1-5` | 用被告品牌、型号、备案号和派生主体查许可、认证和备案。 |
| `1-1-6` | 用被告商品、型号和派生主体查采购、招标和供应记录。 |
| `1-1-7` | 用被告派生主体、发明人、地址和产品技术查专利申请。 |
| `1-1-8` | 用被告商品、品牌和派生主体查进出口记录。 |
| `1-2-1` 至 `1-2-5` | 用被告商品、品牌、店铺、账号、型号、电话和图片查宣传、电商、本地生活、采购、加盟、连锁及其他销售渠道。 |
| `1-3-1` 至 `1-3-3` | 用被告派生主体、项目名、生产地址和被告商品类别查投资、产线、产能、采购和政府批文。 |
| `1-3-4` | 先查被告商品、品牌和主体的市场份额或产销量；没有单品数据时再查严格对应的中性行业类别。 |
| `1-3-5` 至 `1-3-6` | 查被告主体及其母子公司、年报、招股书、注册资本和经营基础。 |
| `1-4-1` 至 `1-4-2` | 用被告商品、店铺、主体和物流、进出口线索核查国内外销售地域。 |
| `1-5-1` | 用被告商品、型号和供应主体查中标、合同、验收、数量和金额；原表列出的监管平台不能单独证明中标数量。 |
| `1-5-2` | 查被告主体披露的涉案商品或对应业务销量、价格和收入。 |
| `1-5-3` | 先查被告商品和品牌的第三方销量；无单品数据时仅使用对应类别数据并披露局限。 |
| `1-5-4` | 固定被告商品、主体和账号对销量、门店、出货和产能的自认。 |
| `1-5-5` | 以被告商品名、型号、图片、店铺和主体跨平台逐 SKU、逐店汇总。 |
| `2-1-1` | 查被告主体及其涉案业务毛利率、净利率。 |
| `2-1-2` | 优先查被告同类业务，再查同类第三方企业和中性行业数据；不得默认改查原告利润率。 |
| `2-2-1` 至 `2-2-2` | 仍以被告商品涉及的具体权利或技术争点为入口；原告权利证书、许可原件或官方登记仅作权利核验材料，不开展原告商品渠道检索。 |
| `2-2-3` 至 `2-2-8` | 以被告商品为调查对象；需要专家、问卷、评论、AI 或横纵向比较时，原告正品或权利材料只能作为对照输入，不能替代被告样本。 |
| `2-3-1` 至 `2-3-5` | 唯一原告产品检索白名单：调查原告广告代言、消费者评价、新闻、销量覆盖、行业排名和评奖。 |
| `3-1-1` 至 `3-1-2` | 从被告商品可见标识和涉嫌使用的权利类型出发；原告实物、权利证书或登记信息只用于核对标识和权利状态，不扩展为原告商品销售调查。 |
| `3-1-3` | 以被告经营地域、行业经历、履历和接触机会为主；引用 `2-3` 已取得的原告知名度证据，不重复把原告产品作为主检索对象。 |
| `3-1-4` | 逐项核对被告商品、包装和宣传行为；原告权利材料仅作为权利对照。 |
| `3-1-5` 至 `3-1-6` | 查被告主体、控制人、关联人、被告商品矩阵、历史侵权、处罚和商标申请。 |
| `3-2-1` 至 `3-2-3` | 从被告主体及控制人出发，核查其与原告之间的代理、劳动、诉讼或和解关系；原告名称仅作为关系查询限制词。 |
| `3-2-4` | 查被告主体及被告商品受到的行政查处。 |
| `3-2-5` | 查针对被告及被告商品的通知、投诉、警告、送达和警告后行为。 |
| `3-2-6` | 先查被告及关联人的商标申请，再与原告标识或其他在先标识比较。 |
| `4-1` | 以被告商品涉嫌侵犯的具体权利号或权利对象筛选可比案件；原告名称可作案件限制词，但不检索原告商品渠道。 |
| `4-2` | 围绕本案被告行为产生的律师、公证、测购、调查等费用；原告票据仅是本案费用原件，不是原告商品检索。 |
| `5-1` | 从被告所在地、侵权行为地、销售地派生地区经济数据。 |
| `5-2-1` 至 `5-2-3` | 被告个人情况；仅在合法必要且由律师控制时人工核查，不主动开展网络画像。 |
| `5-3-1` 至 `5-3-2` | 查被告主体、经营者、控制人和关联公司的财产、融资、执行、失信及破产线索。 |

## 五、原告产品检索唯一白名单

只有以下条目可以把原告品牌或原告商品作为独立主查询词：

- `2-3-1`：原告广告投入和明星代言。
- `2-3-2`：原告商品消费者评价。
- `2-3-3`：原告品牌、商品或权利的新闻报道。
- `2-3-4`：原告商品销量、门店和用户覆盖。
- `2-3-5`：原告品牌、商品或权利的行业排名和评奖。

权利登记、权利证书、许可合同、原被告关系或诉讼案件中出现原告名称，不等于获准检索原告产品。相关材料只在对应行内用于核验权利、关系或对照，不得扩展到原告商品页面、旗舰店、销量和评价。

## 六、比较材料边界

比较类调查必须先有被告商品样本。原告正品、权利证书或官方资料只能作为对照材料，并分别记录来源。

- 被告页面证明被告页面实际展示的名称、包装、价格、店铺和宣传内容。
- 原告材料证明原告权利、原告商品外观或原告知名度，不证明被告的销售、主体、销量或恶意。
- 相似性、混淆、贡献率和恶意属于分析结论，不能仅凭原告资料得出。
- 未取得被告商品页面、图片或实物时，比较行应标 `BLOCKED`、`NEEDS_HUMAN` 或 `LEAD_ONLY`，不得只凭原告商品完成比较。
- 消费者评论必须确认评论对象是被告商品；泛化的原告好评不能证明混淆。
- AI 相似性评价仅作辅助线索，不是权利状态、侵权成立或消费者实际混淆的证据。
- 引用原告知名度时优先复用 `2-3` 已核验结果，避免在其他行再次扩大原告检索范围。

## 七、禁止反向替代

- 原告官方商品页不能证明被告商品名称、价格、销量、渠道、备案、产能或经营主体。
- 原告旗舰店不能计入被告店铺数量、销售范围或多店销量。
- 原告集团营收、产能、员工数和市场覆盖不能写入被告规模或偿付能力。
- 只找到原告商品材料时，被告相关条目不得标为 `COMPLETE_VERIFIED` 或 `PARTIAL_VERIFIED`。
- 被告商品名称尚未提取时，不得用原告品牌名替代种子词。
- 第三方页面出现原告品牌，不代表其中商品就是被告涉案商品；必须与种子链接、型号、店铺、主体或图片形成对应。
- 同名主体、同图商品、相似包装和相似标题都只是扩线线索，未经交叉核验不得自动归入被告销售矩阵。
- 权利人资料不得跨行复用为被告事实；一项来源只能证明其直接载明的范围。

## 八、查询示例

假设侵权链接提取到：被告商品名为“COIFL 保湿洁颜泡沫”，店铺为“德瑞克健康用品店”，经营主体为“莆田德瑞克医疗器械有限公司”，权利人为“珂润”。

正确查询：

- `"COIFL 保湿洁颜泡沫"`
- `"COIFL" "洁颜泡沫"`
- `"COIFL 保湿洁颜泡沫" "德瑞克健康用品店"`
- `"COIFL" "莆田德瑞克医疗器械有限公司"`
- `site:taobao.com "COIFL 保湿洁颜泡沫"`
- `site:pinduoduo.com "COIFL" "洁颜泡沫"`
- `"莆田德瑞克医疗器械有限公司" 备案 化妆品`
- `"莆田德瑞克医疗器械有限公司" 专利`
- 在 `2-2-5` 混淆调查中：`"COIFL 保湿洁颜泡沫" "珂润"`，但结果必须核验评论对象和上下文。
- 在 `2-3-3` 原告知名度白名单中：`"珂润" 洁颜泡沫 新闻`。

错误查询：

- 在 `1-2-4` 用 `"珂润 洁颜泡沫"` 搜索后，把珂润旗舰店写成被告销售渠道。
- 在 `1-5-5` 汇总珂润官方店销量，作为 COIFL 商品销量。
- 在 `1-1-5` 用珂润商品备案证明 COIFL 商品已经备案或没有备案。
- 在 `2-1-1` 用花王集团利润率代替被告自身利润率。
- 在 `3-1-5` 搜索珂润历史案件后，写成被告是重复侵权人。
- 因被告页面受阻，直接根据珂润官方产品页推断被告商品标题、店铺、价格或生产商。
