# 使用说明 · How to Use

这份 skill 是通用的法律工作标准作业程序（SOP），不绑定任何特定 AI 产品。三种用法任选：

## 用法一：支持 skill 机制的 AI 助手（Claude Code、Codex、Cursor 等）
把整个文件夹放进该工具的技能目录（如 Claude Code 的 ~/.claude/skills/），重启后在对话中说出触发语即可自动执行。

## 用法二：网页版 AI（Kimi、豆包、Coze、ChatGPT 等）
打开 SKILL.md 全选复制，粘贴到对话框，请 AI「按此作为固定工作流程执行」。references/ 与 templates/ 里的文件可作为附件一并上传。

## 用法三：任何支持自定义指令 / 知识库的 AI 工具
把 SKILL.md 设为系统指令或存入知识库，范本与参考文件一并入库。

注：LINKS.md（如有）列出的外部大文件请按链接自行获取。
